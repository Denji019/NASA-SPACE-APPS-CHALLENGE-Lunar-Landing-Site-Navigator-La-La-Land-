# NASA-SPACE-APPS-CHALLENGE-Lunar-Landing-Site-Navigator-La-La-Land-
SELENE-3D: Lunar Site Explorer

SELENE-3D is a browser-based 3D Moon built as one self-contained HTML file with three.js. It maps real NASA LRO LOLA elevation onto the globe and lets users compare candidate landing sites. Users click any two points, or type in coordinates, and compare them on 13 mission factors. These include sunlight and darkness over 30 days, Earth visibility and comms link, terrain and horizon, landing slope, hazards, thermal conditions, traverse, and distance to permanently shadowed regions (PSRs) for ice access. Sun and Earth geometry comes from embedded Astronomy Engine, with live JPL Horizons as a source. Users can import CSV, GeoJSON or remote datasets. Where data is missing, the tool shows “Awaiting source data” and links to the NASA sources instead of inventing numbers.

A rover and explore mode lets users drive a 3D rover-cam across the LOLA-shaped surface. Landmark beacons mark Apollo and other sites, and Fast Travel compresses a journey to seconds while the HUD keeps showing true distance, speed and drive time.

It matters because it turns scattered lunar data into a transparent, source-linked tool for choosing where to land.
